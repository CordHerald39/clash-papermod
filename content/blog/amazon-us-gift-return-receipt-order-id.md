在美国 Amazon 收到礼物后若不合用需要退回，适用场景是：你是收礼人，手里有装箱单或电子礼品收据上的 17 位订单号，并准备走礼品退货，而不是把未在本页展开的普通买家退货套进同一套流程。处理方向是：先核对订单号能否用于 Returns Center、以及退款会发到哪里；材料写明经 Returns Center 发起后，退款形式为 Amazon.com Gift Card。不要承诺送礼者永远不会知道，也不要假定所有商品适用同一退货期限。实际资格以 Returns Center 核对结果为准。

## 先核对礼品收据、订单号和退款去向

礼品退货的入口信息是 17 位订单号。该号码印在装箱单上，或出现在电子礼品收据里。没有这两样之一，本篇官方说明没有提供另一套收礼人发起方式，不要猜测号码，也不要改用未在本页描述的普通买家退货来「顶替」礼品流程。

退款去向必须单独核对：经 Returns Center 完成礼品退货后，发放的是 Amazon.com Gift Card，而不是把钱退回送礼者当时的付款方式。若你的目标是让原支付渠道收回款项，本材料并未把那条路径写成礼品退货的结果，两条线不要混用。礼品退货解决的是收礼人凭收据/订单号处理礼物；普通买家退货则是购买人处理自己的订单，操作人、退款落点和是否通知购买人都不是同一套说明。

本说明也没有列出统一的退货天数或「所有礼物同一期限」。能否退、能退哪些件，只能以 Returns Center 用订单号核出的资格为准，不能按自行估计的期限批量操作。

## 在 Returns Center 用订单号发起

准备好 17 位订单号后，前往 Returns Center，按提示输入该订单号。材料没有列出更多按钮名称、面单打印或投递点步骤，输入之后以当时屏幕指示为准，不要对照未出现在本说明中的菜单去点。

分支一：装箱单或电子礼品收据齐全，订单号可被接受——按 Returns Center 提示继续，退款形式按材料为 Amazon.com Gift Card。分支二：只有礼物实物、找不到订单号——本说明没有给出替代检索办法，无法按本流程发起。分支三：你想改走普通买家退货——那是另一条路径，本页没有把它的步骤、退款方式和通知规则写成与礼品收据流程相同；混用不能声称结果一致。

官方新闻称希望礼品退货体验顺畅、尽量不惊动对方，这是目标表述，不是对每笔订单的结果承诺。提交前再看一眼退款是礼品卡、以及该订单是否仍显示可退。

## 送礼者是否会收到通知、例外和常见失败

多数情况下，送礼者不会因为你退货而收到通知，因为 Amazon 不会向购买人发送通知。例外包括价值超过 2,000 美元的商品。即便低于该金额，材料用的是多数时候，不能写成「永远不知道」或「一定匿名」。2,000 美元只用于说明通知例外，不要把它理解成低于该金额就保证保密，也不要编造其他金额线。

常见失败：把礼品退货当成购买人原路退款；没有礼品收据或装箱单仍强行输入猜测的订单号；把未展开的普通买家退货说成 discreet 礼品退货；把「多数时候不通知」说成绝对匿名；自行套用未在本页出现的统一退货期限；把超过 2,000 美元的高价值礼物按「对方不会知道」来规划。材料未保证所有商品都可退，也未保证 Returns Center 始终能完成核对。
