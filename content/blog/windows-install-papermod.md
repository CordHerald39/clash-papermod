重装 Windows 会清掉本机程序和数据。Clash 电脑端（Clash Verge Rev）官方写明：不收集用户数据，配置与日志只留在本地。因此重装前要做的是列出一份「新系统装完后必须恢复」的清单：安装包怎么选、服务和 TUN 是否还要用、订阅与覆写从哪来。清单对得上，才不会只装回程序却丢了配置。

## 先列出安装与运行方式

这些项决定重装后下哪一个包、用哪种权限。

记下处理器架构：常见 64 位还是 ARM64，分别对应 `Clash.Verge_*_x64-setup.exe` 与 `*_arm64-setup.exe`，不能混用。记下安装包类型：正常版本（推荐）还是内置 WebView2 版；后者仅企业系统或无法安装 WebView2 时使用。新系统若仍装不上 WebView2，清单须写明继续用 `*_fixed_webview2-setup.exe`。记下发行通道与版本 tag：日常用 Stable；AutoBuild 可能有缺陷。重装后到 Release 页取同一通道的文件。Windows 已不再支持 Win7，新系统也必须满足这一条件。

记下内核与模式：是否切换过 Alpha 内核；当前走系统代理还是 TUN；是否已安装服务模式。未装服务时，普通权限可能无法启动内核。重装后服务一定不在，清单要写清「是否需要重新安装服务」。记下日常运行账户：官方修过首次以管理员启动后数据目录所有权不符、服务拒绝启动内核的问题，须避免管理员与普通用户混用数据目录。

## 再列出订阅、覆写与界面项

安装包不能代替配置。按官方功能把当前生效内容逐条写下来：

订阅与配置文件：每个订阅地址或本地配置的用途；是否使用代理集合、规则集合。不同来源的订阅或规则集共用缓存路径，曾导致服务模式无法启动内核，来源要分开记录。配置增强：是否使用 Merge、Script；DNS 覆写是否开启、是否按订阅独立记忆；订阅是否含自定义 DNS。官方修过「含自定义 DNS 的订阅在确认开启覆写后重启被关掉」、Merge 覆写 DNS、过滤条件和 hosts 时旧条目仍被保留等问题，因此每个订阅的覆写开关和自定义内容都要进清单，而不是只记一个全局开关。另记节点与规则的本地编辑，以及主题颜色、代理组或托盘图标、CSS Injection。系统代理守卫与 TUN 在重装后默认不存在，须按清单再打开。

## 备份通道与对不上时的下一步

官方功能包含 WebDav 配置备份和同步。若已经在用，清单注明所用 WebDav 服务信息，凭据自行安全保存，作为重装后的配置来源。若从未使用 WebDav，本地配置会随系统消失，只能按抄录的订阅、Merge/Script、DNS 覆写和界面项重新填入。不存在官方云端代管。服务自身运行日志会保存到文件；安全检查失败时会说明原因并提供修复文档链接。重装前若服务或 TUN 已有异常，把当时的原因一并记下，以免新系统重复同一类权限误判（系统盘根目录删除权限、系统隔离、路径或目录权限、提示「program not found」、旧服务残留）。

对不上时：新系统仍是 Win7 → 先升级再装。架构或 WebView2 条件变了 → 改选对应安装包，不要沿用旧文件。服务或 TUN 不可用 → 按该版本给出的原因和修复文档处理，必要时重新安装服务；旧服务残留时，较新版本会备份可识别残留并恢复安装。不要首次只用管理员启动再切回普通用户。DNS 覆写重启后不对 → 按订阅逐条核对，不要只改一次全局项。没有 WebDav 且清单不全 → 官方渠道只能重装程序，未记录的本地改动无法取回。清单完成后再重装系统：先按架构与 WebView2 条件安装 Stable 包，再按需安装服务，最后按订阅与覆写逐条恢复。
